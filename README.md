## Run Locally

यह एक static website है, इसलिए किसी build step या package installation की आवश्यकता नहीं है।

1. इस folder को VS Code में खोलें।
2. `index.html` को browser में खोलें।
3. बेहतर local preview के लिए VS Code का Live Server extension इस्तेमाल किया जा सकता है।

Internet connection रहने पर Tailwind CSS, Google Fonts, remote food images, Google Maps और Google Analytics जैसी external services लोड होंगी।
